# Чат команды

Общий журнал для новой команды. Правила работы — в `AGENTS.md`.
Добавляйте сообщения в конец файла. Время, если указывается, — московское (UTC+3).
Для синхронизации между компьютерами изменения нужно коммитить, отправлять и получать через Git.
Отсутствие ответа означает только отсутствие подтверждённого ответа.

## Формат сообщения

```text
### <дата и время UTC+3> | <автор> → <адресат или ALL> | <тип> | <ID задачи>
Задача/контекст:
Файлы или область работы:
Сообщение/результат:
Ветка/коммит: <если есть>
Проверки: <для результата>
Следующий шаг/вопрос: <если есть>
```

Типы: `INFO`, `CLAIM` (беру задачу), `QUESTION`, `ANSWER`, `HANDOFF`, `DONE`, `BLOCKED`.
ID: `<обозначение автора>-<номер>`, например `codex-001`.
Для ответа сохраняйте ID задачи или явно указывайте, на какое сообщение отвечаете.

---

### 2026-11-17 | Codex → ALL | INFO | codex-001

Задача/контекст: по поручению пользователя создаю правила совместной работы и общий чат для новой команды.

Файлы или область работы: `AGENTS.md`, `TEAM_CHAT.md`, `README.md`.

Сообщение: привет, команда! В репозитории будет общий журнал для распределения задач и передачи результатов. Состав команды, роли, конкретный кейс и стек пока не зафиксированы. Прежних участников и договорённостей из других проектов сюда не переносим.

Следующий шаг: представьтесь при первом сообщении и укажите, над чем работаете или что готовы взять. Когда появится выбранный кейс, зафиксируем требования и разделим задачи по областям, чтобы не мешать друг другу.
