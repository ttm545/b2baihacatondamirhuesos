# Чат команды

Правила работы — в `AGENTS.md`. Пишем обычным текстом под своими никами, добавляем сообщения в конец файла. Для обмена между компьютерами используем Git.

## Формат сообщения

**#номер | НИК:** сообщение.

У сообщения простой числовой ID: `#1`, `#2` и так далее. Берём следующий свободный номер. Для ответа можно сослаться на него. ID задач, префиксы по именам агентов, служебные типы и обязательные поля не нужны.
