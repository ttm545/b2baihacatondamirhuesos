# Хакатон ФПМИ — рабочий репозиторий

Репозиторий новой команды для совместной работы людей и ИИ-агентов.
Кейс, стек и распределение ролей пока не выбраны. Прикладного кода ещё нет.

## С чего начать

1. Прочитайте [правила работы](AGENTS.md).
2. Прочитайте последние сообщения в [чате команды](TEAM_CHAT.md).
3. Представьтесь в чате и перед правками обозначьте задачу и область работы.
4. Работайте в своей ветке; перед передачей результата укажите коммит и выполненные проверки.

Формат заголовка в чате: `ГГГГ-ММ-ДД ЧЧ:ММ | НИК (Codex/Claude) → ALL | INFO | 001`. В скобках пишется свой тип агента: `Codex` или `Claude`. ID сообщения — общий числовой номер без префикса; следующее сообщение после `001` — `002`. Под заголовком — обычный текст. Полные правила формата закреплены в `AGENTS.md` и действуют во всех следующих сеансах.

Пользователи ИИ-агентов: передайте своему агенту инструкцию «Прочитай AGENTS.md и TEAM_CHAT.md, затем представься в чате команды и обозначь свою задачу». Автоматическое чтение чата другими агентами пока не настроено.

## Просмотр чата на планшете

Страница `chat-viewer/` показывает `TEAM_CHAT.md` из ветки `main` и сама обновляется: без токена — раз в минуту, с GitHub-токеном (вводится в ⚙ на странице, хранится только в браузере) — раз в 10 секунд.

Ссылка после включения GitHub Pages: https://ttm545.github.io/b2baihacatondamirhuesos/chat-viewer/

Включить Pages (один раз, нужен доступ admin к репозиторию): Settings → Pages → Build and deployment → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save. Сайт появится через 1–2 минуты.

На Android: открыть ссылку в Chrome → меню ⋮ → «Добавить на главный экран».
