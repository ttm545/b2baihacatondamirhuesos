# Хакатон ФПМИ — рабочий репозиторий

## Кейс VK — «Умный поиск в Почте»

Нужно сделать веб-прототип почты для просмотра писем и поиска по предоставленному архиву анонимизированных писем. Пользователь описывает письмо своими словами и получает ранжированную выдачу, даже если в письме использованы другие формулировки. Главная задача — улучшить качество и скорость поиска по сравнению с обычным полнотекстовым поиском. Подход и сценарии команда выбирает сама.

- **Оценка.** Для разработки организаторы дают публичный бенчмарк. Итоговые качество и скорость они замерят на приватном. Серверный p99 должен быть строго меньше 1 секунды с учётом обработки запроса, поиска и ранжирования. Превышение снижает оценку.
- **Модели.** Использование API моделей или моделей свыше 3 млрд параметров при отборе кандидатов или переранжировании снижает оценку.
- **Что сдаём.** Репозиторий с исходным кодом и инструкцией запуска, рабочее веб-демо и защиту. Демо можно показать на localhost. За публикацию сервиса в интернете дают 1 дополнительный балл. Полезные функции почты сверх поиска — необязательный бонусный трек.

## С чего начать

1. Прочитайте [правила работы](AGENTS.md).
2. Прочитайте последние сообщения в [чате команды](TEAM_CHAT.md).
3. Подпишите сообщение именем владельца и типом агента. Перед правками обозначьте задачу и область работы.
4. Работайте в своей ветке; перед передачей результата укажите коммит и выполненные проверки.

Пример заголовка: `ГГГГ-ММ-ДД ЧЧ:ММ | Дамир (Codex) → ALL | INFO | 001`. Номер сообщения общий для команды. [Формат и типы сообщений](AGENTS.md#чат-команды) описаны в правилах.

Пользователи ИИ-агентов: попросите своего агента прочитать описание кейса, правила и чат, затем отметиться в чате под вашим именем. Автоматическое чтение чата пока не настроено.

## Запуск почты и API

Из корня репозитория выполните команды для Python 3.11+ (Linux/macOS). В `VK_DATA_DIR` укажите каталог с распакованным `documents.jsonl`.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-api.txt
export VK_DATA_DIR=/path/to/unpacked/archive
python -m uvicorn vk_mail_search.api:app --host 127.0.0.1 --port 8000
```

Откройте [почту](http://127.0.0.1:8000/) и выберите ящик. Можно листать письма, искать по фразе, ограничивать поиск датой и открывать полный текст. Интерактивное описание четырёх маршрутов доступно в [Swagger UI](http://127.0.0.1:8000/docs).

Временный поиск ранжирует письма по числу вхождений подстроки без учёта регистра. Письма без даты участвуют в поиске при любой дате запроса. Для подключения другого движка передайте в `create_app(search_factory=...)` фабрику, принимающую `MailStore` и возвращающую поисковик с методом D3. Исходные записи доступны через `store.by_id.values()`. Фабрика вызывается один раз при старте процесса.
