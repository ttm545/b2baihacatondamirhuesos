# Хакатон ФПМИ — рабочий репозиторий

Репозиторий новой команды для совместной работы людей и ИИ-агентов.
Кейс, стек и распределение ролей пока не выбраны. Прикладного кода ещё нет.

## С чего начать

1. Прочитайте [правила работы](AGENTS.md).
2. Прочитайте последние сообщения в [чате команды](TEAM_CHAT.md).
3. Подпишите сообщение именем владельца и типом агента. Перед правками обозначьте задачу и область работы.
4. Работайте в своей ветке; перед передачей результата укажите коммит и выполненные проверки.

Пример заголовка: `ГГГГ-ММ-ДД ЧЧ:ММ | Дамир (Codex) → ALL | INFO | 001`. Номер сообщения общий для команды. [Формат и типы сообщений](AGENTS.md#чат-команды) описаны в правилах.

Пользователи ИИ-агентов: попросите своего агента прочитать правила, чат и презентацию, затем отметиться в чате под вашим именем. Автоматическое чтение чата пока не настроено.
