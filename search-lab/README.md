# Проверка поиска VK

Статический интерфейс для базового теста корпуса. Для локального запуска из этого каталога:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/. Загрузите ZIP организаторов кнопкой «Открыть ZIP». Архив остаётся в браузере. Можно выбрать запрос из набора, проверить его ящик и дату, открыть письмо или посчитать метрики на вкладке «Бенчмарк». Локальный p99 измеряет только поиск в текущем браузере. Кнопка «Скачать выдачу» сохраняет JSONL с полями `query_id` и `doc_ids` для локальной проверки.

По умолчанию открыт небольшой демонстрационный набор. Реализован лексический BM25 без семантической модели. Разметка используется только при расчёте метрик. Сервер для хранения корпуса и вызовы внешних API не нужны.

Для публикации разместите `index.html`, `style.css` и файлы `*.mjs` в одном каталоге веб-сервера. Для `.mjs` нужен MIME-тип `text/javascript` или `application/javascript`.
