# Поиск с локальной оценкой тем писем

Изолированный вариант использует обычный `period` для подбора кандидатов. В первых десяти позициях локальная модель сравнивает содержательную часть запроса с явно указанными темами писем. Одинаковые темы оцениваются один раз. Тело письма и индекс векторов не используются.

По умолчанию Jina получает запрос и список тем вместе. Косинусные оценки Jina приводятся к шкале от 0 до 1 внутри запроса с минимальным масштабом 0,25, чтобы близкие оценки не превращались в большой штраф или бонус. Qwen доступен для сравнения; он оценивает каждую пару по логитам `yes` и `no`.

К линейному баллу позиции `period` от 1 до 0 добавляется оценка модели, умноженная на `VK_SUBJECT_WEIGHT`. Переставляются только оценённые письма. Письма без явной темы, письма вне распознанного периода и позиции после первой десятки остаются на своих местах. Для запроса без смысловой части работает обычный `period`.

## Запуск

Установите зависимости из корня репозитория. В первом запуске Transformers скачивает веса. После загрузки можно использовать `HF_HUB_OFFLINE=1`.

```sh
python -m pip install -r requirements-baseline.txt -r requirements-api.txt -r solutions/title_rerank/requirements.txt
VK_DATA_DIR=data VK_SUBJECT_DEVICE=mps \
  python -m uvicorn solutions.title_rerank.api:create_app --factory --port 8001
```

На CPU используйте `VK_SUBJECT_DEVICE=cpu` или опустите переменную. `VK_SUBJECT_MODEL=qwen` переключает модель. Для обеих моделей вес по умолчанию 0,35. `VK_SUBJECT_WEIGHT=0` запускает тот же интерфейс с обычным `period` без загрузки модели.

```sh
python -m solutions.title_rerank.benchmark --model jina --data-dir data --device mps --out .cache/title-jina
python -m solutions.title_rerank.benchmark --model qwen --data-dir data --device mps --out .cache/title-qwen
python -m unittest solutions.title_rerank.test_searcher
```

Бенчмарк сравнивает веса 0,10 / 0,20 / 0,35 / 0,50 на 44 разработочных перефразировках. Выбранный по nDCG@5 положительный вес затем сравнивается с обычным `period` на 32 отложенных перефразировках и 99 публичных запросах. Команда записывает отдельные выдачи, оценки тем и агрегированные результаты.

## Сравнение

| Срез и метрика | period | Qwen | Jina |
| --- | ---: | ---: | ---: |
| 99 публичных · Recall@5 | 0,8516 | 0,8516 | 0,8516 |
| 99 публичных · nDCG@10 | 0,9906 | 0,9893 | 0,9905 |
| 32 отложенные · Recall@1 | 0,3015 | 0,3015 | 0,2953 |
| 32 отложенные · Recall@2 | 0,3708 | 0,3770 | 0,3708 |
| 32 отложенные · Recall@5 | 0,5437 | 0,5437 | 0,5437 |
| 32 отложенные · nDCG@10 | 0,7103 | 0,7117 | 0,7060 |

Последовательные локальные вызовы при K=10 на Apple M4 через MPS, без HTTP и очереди:

| Срез | Qwen p50 / p99 | Jina p50 / p99 |
| --- | ---: | ---: |
| 99 публичных | 112 / 863 мс | 141 / 823 мс |
| 32 отложенные | 531 / 996 мс | 305 / 695 мс |

Обе модели оценивали темы в 55 из 99 публичных запросов и в 25 из 32 отложенных. Jina поменяла порядок в 14 и 10 запросах соответственно. На запрос о том, что купили, Jina подняла реестр платежей выше чека. Эта ошибка отражается в Recall@1 отложенного среза.
