# Базовый поиск и оценка VK

Для этой ветки нужен Python 3.11+.

1. Скачайте [ZIP организаторов](https://cloud.mail.ru/public/8S62/oQDJV17v6) и распакуйте за пределы отслеживаемых файлов Git. Укажите каталог, в котором непосредственно лежат три JSONL.
2. Установите зависимости BM25.
3. Запустите оценку. Для готовой выдачи установка pymorphy3 не нужна.

```sh
python -m pip install -r requirements-baseline.txt
python -m vk_mail_search.data --data-dir /path/to/dataset
python -m vk_mail_search.evaluate --data-dir /path/to/dataset --searcher bm25 --k 10 --out predictions-bm25.jsonl
python -m vk_mail_search.evaluate --data-dir /path/to/dataset --pred predictions-bm25.jsonl
```

Вместо `--data-dir` можно задать `VK_DATA_DIR`. По умолчанию используется `data/`. Команда `data` выводит агрегаты с размерами корпуса, признаками формата и распределением релевантных писем. Тексты писем в отчёт не попадают.

Оценка считает макросреднее Recall, nDCG и MRR на `@5`, `@10`, `@20` и дополнительно на указанном K. Запросы без положительной разметки исключаются из среднего, число оценённых запросов выводится явно. Выдача в `--pred` должна иметь один результат на запрос и не содержать повторов, писем из других ящиков и писем будущих дат. При экспорте на K=10 оценка файла на @20 использует только доступные 10 позиций. Для сравнения на всех трёх глубинах сохраняйте выдачу с `--k 20`.

При прогоне поисковика отдельно измеряется вызов `search` на запрошенном K после прогрева. Время индексации и HTTP-слоя сюда не входят. У файловой выдачи измерения задержки нет.

После объединения с веткой `task/vk-search-dense` запустите ту же команду с `--searcher dense`. Путь к готовому индексу передайте через `VK_CACHE_DIR`, чтобы повторные прогоны использовали сохранённые векторы.

## Замер на архиве организаторов

Проверены все четыре SHA-256 из `manifest.json`. В наборе 16 376 писем, 12 ящиков, 99 запросов и 565 положительных связок. В `doc` сама тема указана строкой `Тема:` у 13 187 писем. Строка `От:` встречается у 7 324 писем. Есть ещё варианты `От кого:` и `Отправитель:`. Длина текста в символах: медиана 656, p95 1 054, максимум 15 724. HTML-подобные теги обнаружены в 10 документах. У 433 писем дата неизвестна. У 42 запросов по одному релевантному письму. Максимум — 65. Проверка ящика и даты совпала со всеми положительными примерами. В 26 запросах сработал шаблон временных выражений.

| K | Recall | nDCG | MRR |
| --- | ---: | ---: | ---: |
| 5 | 0.3689 | 0.3026 | 0.3210 |
| 10 | 0.4807 | 0.3489 | 0.3452 |
| 20 | 0.6137 | 0.3989 | 0.3538 |

Оценены 99 из 99 запросов после исправления индексации email. На Windows 11, Python 3.12.14, после 10 прогревочных вызовов для K=10 получено p50 0,25 мс, p95 4,58 мс, p99 6,05 мс. Это один последовательный прогон локального поисковика без HTTP и нагрузки.
