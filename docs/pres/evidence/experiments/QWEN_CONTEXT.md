# Ранжирование с контекстом Qwen

Qwen3-VL-Embedding-2B заранее читает тему и начало письма как одну последовательность и выдаёт контекстный вектор. В опыте использовано до 220 символов подготовленного текста письма. Смысл оценивается по близости контекстных векторов. Текстовые признаки `period` отдельно учитывают совпадения слов.

Для CPU обучена проекция, которая переносит контекст Qwen в компактный индекс. Qwen закодировал 216 писем, выбранных по фиксированному случайному разбиению внутри каждого ящика, без использования оценок релевантности. Из них 168 использованы для обучения проекции, 48 оставлены для проверки. Средний косинус между предсказанным и точным центрированными векторами в 64-мерном пространстве Qwen на этих 48 письмах составил **0,8915**.

При запуске `context` готовит 64-мерные контекстные координаты для всех **16 376 писем**. Затем на запросе вычисляется только вектор запроса, и движок ранжирует готовые векторы кандидатов. При сильном совпадении слов темы выдача сохраняет порядок `period`. При запросах без даты используется гибрид BM25 и RuBERT из [предыдущего эксперимента](CONTEXT_INDEX.md).

## Как обучено

- Qwen закодировал 175 формулировок. Для обучения проекции запросов и подбора параметров использованы 44 перефразировки и 55 исходных запросов восьми разработочных семейств. Остальные четыре темы и 32 их перефразировки исключены из обучения и подбора параметров. Qwen-представления отложенных запросов используются только для диагностической оценки точного Qwen-запроса.
- Обучается небольшая голова в PyTorch, которая сопоставляет релевантные и нерелевантные письма внутри периода. Среди вариантов сравниваются добавление её балла к `period` и объединение двух порядков по обратным рангам. Подбор выполнен с исключением одного семейства за раз. Проекция запроса, голова и адаптер RuBERT обучаются внутри каждого блока. Уже готовый профиль `period` остаётся общей отправной точкой.
- Параметры Qwen и RuBERT заморожены. На запросах режим `context` выполняет один вызов компактного энкодера, когда он нужен для пересортировки. Веса Qwen нужны для повторного обучения и эксперимента с точными эмбеддингами.

## Сравнение с `period`

| Поиск | Публичные 99 · nDCG@10 | 32 отложенные перефразировки · Recall@5 | Перефразировки · nDCG@5 | Перефразировки · Recall@10 | Перефразировки · nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `period` | 0,9906 | 0,5437 | 0,6518 | **0,7538** | 0,7103 |
| Тот же эксперимент без признака Qwen | 0,9887 | **0,5752** | **0,6575** | 0,7452 | 0,7094 |
| Qwen, пересортировка всего пула периода | 0,9915 | 0,5724 | 0,6542 | 0,7273 | 0,6987 |
| **Qwen, пересортировка первой десятки** | **0,9924** | **0,5661** | 0,6508 | **0,7538** | **0,7114** |

Ограниченный режим поднял Recall@5 на отложенном срезе на **2,24 п.п.** и улучшил nDCG@10 на обоих срезах. Состав топ‑10 и порядок после него совпали с `period` для всех 131 запроса. MRR@10 на перефразировках снизился с **0,7443 до 0,7315**. В абляции компактная модель без признака Qwen дала лучший Recall@5 на перефразировках, поэтому вклад именно Qwen нельзя считать доказанным на новых темах. Закрытые запросы в оценке отсутствуют.

CPU i5-13420H, один процесс Uvicorn, восемь параллельных клиентов, K=10. После прогрева прошли все 1 000 запросов по 99 публичным формулировкам. p99 составил **363,1 мс внутри API** и **365,8 мс по локальному HTTP**.

## Запуск

Воспроизведите полноархивный индекс RuBERT по [README](README.md). Возьмите те же пути из [инструкции запуска API](CONTEXT_INDEX.md) и добавьте:

```powershell
$env:VK_CONTEXT_MODE = "context"
$env:VK_CONTEXT_ADAPTER = "solutions/tiny_encoder/assets/qwen-context.npz"
python -m uvicorn solutions.tiny_encoder.routed_api:create_routed_app --factory --host 127.0.0.1 --port 8000
```

Повтор обучения с локальным Qwen из [инструкции](CONTEXT_INDEX.md):

```sh
python -m solutions.tiny_encoder.qwen_teacher --data-dir data --cache .cache/qwen-docs.sqlite --output .cache/qwen-teacher
python -m solutions.tiny_encoder.train_qwen_context --data-dir data --model .cache/rubert-tiny-retriever --projection solutions/tiny_encoder/assets/projection-80.npz --index .cache/tiny-fast.npz --adapter solutions/tiny_encoder/assets/adapter-80.npz --teacher .cache/qwen-teacher --out .cache/qwen-context.npz
```

Для сравнения режимов можно задать `VK_CONTEXT_DEPTH=0`, чтобы открыть весь пул периода для пересортировки. Готовые коэффициенты по умолчанию используют глубину 10.

Выборка писем, полные векторы Qwen, разметка и индексы остаются вне Git. Для запуска режима используется компактный обученный файл коэффициентов.
