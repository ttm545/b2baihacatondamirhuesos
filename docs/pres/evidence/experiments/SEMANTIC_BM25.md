# Контекстный BM25 внутри ансамбля

В режиме `ensemble-semantic-bm25` изменён отбор кандидатов существующего ансамбля. Если запрос с датой и в темах писем уже есть сильное текстовое совпадение (`date_gate`), остаётся обычный путь. При слабом совпадении контекстный BM25 отбирает пул в пределах периода. Дальше работают прежние три ранга `period`, `cover` и Qwen-контекст. Без даты обновлённый BM25 становится текстовым источником в тех же четырёх сигналах ансамбля вместе с RuBERT, проекцией Qwen и свежестью.

RuBERT кодирует очищенный запрос целиком. По этому вектору поиск находит 4 ближайших письма в распознанном периоде или 8 писем без периода. Поиск ограничен ящиком и датой запроса. Из тем и первых строк берётся до 8 слов, встретившихся хотя бы в двух письмах. Вес учитывает редкость слова, близость соседнего письма и поле, в котором слово встретилось. Дальше BM25 начисляет баллы за эти слова. Бонус ослабляется для документов, далёких по вектору запроса. Для первых 100 векторных кандидатов есть небольшой дополнительный балл. Поэтому письмо может попасть в пул и при отсутствии общих слов с исходным запросом.

Сравнивались два профиля. Полный использует новый BM25 на всех запросах, прошедших описанный отбор. Мягкий смешивает позиции обычного и нового BM25 по взвешенному reciprocal rank с константой 13. Вес нового ранга — 0,15 с датой и 0,35 без даты. В обоих случаях используются тот же индекс из 16 376 писем и те же веса финального ансамбля. Для мягкого профиля доли выбраны на `tune` с исключением проверяемого семейства из переобучения адаптера запроса. Проекция Qwen и исходная политика ансамбля фиксированы во всех фолдах. Полный профиль выбран отдельной проверкой нескольких коэффициентов контекстного балла на `tune`.

## Как воспроизвести

Установите зависимости и соберите полный компактный RuBERT-индекс по [README](README.md). Для API используйте [те же настройки, что для ансамбля](FINAL_HACKATHON.md), и задайте `VK_CONTEXT_MODE=ensemble-semantic-bm25`. Мягкий профиль подхватывается автоматически. Для полной подмены укажите `VK_ENSEMBLE_BM25_CONFIG=solutions/tiny_encoder/assets/ensemble-semantic-bm25-full.json`. Режимы `semantic-bm25` и `semantic-bm25-period` воспроизводят отдельный первый этап и его вариант с переранжированием `period`, соответственно.

```powershell
$assets = "solutions/tiny_encoder/assets"
$common = @("--data-dir", "data", "--model", ".cache/rubert-tiny-retriever",
            "--projection", "$assets/projection-80.npz", "--index", ".cache/tiny-fast.npz",
            "--adapter", "$assets/adapter-80.npz", "--context", "$assets/qwen-context.npz")
python -m solutions.tiny_encoder.bench_semantic_bm25 @common --ensemble "$assets/ensemble.json" --out .cache/semantic-bm25.json
python -m solutions.tiny_encoder.bench_ensemble_bm25 @common --ensemble "$assets/ensemble.json" --feedback "$assets/semantic-bm25.json" --rule rank-mix --out .cache/ensemble-bm25-mix.json
python -m solutions.tiny_encoder.bench_ensemble_bm25 @common --ensemble "$assets/ensemble.json" --feedback "$assets/semantic-bm25.json" --rule scale --out .cache/ensemble-bm25-full.json
python -m solutions.tiny_encoder.ensemble_predict @common --config "$assets/ensemble.json" --feedback "$assets/ensemble-semantic-bm25.json" --queries data/queries_dev.jsonl --out .cache/predictions-ensemble-bm25.jsonl --k 5
```

Для HTTP-замера запустите API в выбранном режиме и выполните `python -m scripts.load_test --url http://127.0.0.1:8000 --queries data/queries_dev.jsonl --clients 8 --calls 1000 --k 5 --warmup-per-client 6`. Для среза без даты замените поле `query` на `parse_query(query, query_date).topic` в копии JSONL и передайте эту копию в `--queries`.
