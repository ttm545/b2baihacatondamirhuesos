# Материалы VK Mail Search для подготовки презентации

Начните с [полного текстового отчёта](REPORT.md). В нём собраны результаты релиза v1.1, описание алгоритмов, условия замеров, экспериментальные ветки и факты для ответа на вопросы жюри.

| Материалы | Что внутри |
| --- | --- |
| [Полный отчёт](REPORT.md) | Все выводы, контрольные сравнения и ссылки на доказательства. |
| [Доказательства релиза](evidence/pitch/results/) | Паспорт, офлайн-выдачи, сравнение с API, прогоны нагрузки и точные метрики. |
| [Независимая проверка](evidence/review/) | Метрики живого HTTPS-стенда по исходным запросам, перефразировкам и трём вариантам календарной подсказки. |
| [Отчёты по экспериментам](evidence/experiments/) | Подробности обучения, Qwen, ансамбля, контекстного BM25 и внешних наборов. |
| [Манифест источников](evidence/manifest.json) | Исходный коммит или прогон и SHA‑256 каждого файла. |

Основные результаты относятся к релизу [v1.1, 76576ae](https://github.com/ttm545/b2baihacatondamirhuesos/tree/76576ae). Для публичного сравнения используйте единый срез и один K. Результаты локальных ноутбуков и VPS подписывайте отдельно. Материалы содержат числа и ID выдачи синтетического бенчмарка.
