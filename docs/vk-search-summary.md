# VK Tech — умный поиск в Почте

Краткая сводка по презентации организаторов, слайды VK Tech 03 и 05–10. Точные требования — в [официальном условии](vk-mail-search.pdf).

- **Задача.** Найти письма по смыслу, даже когда в запросе и письме разные слова. В веб-прототипе можно ввести запрос, увидеть выдачу и открыть найденное письмо.
- **Данные.** Около 16 000 анонимизированных писем в 12 синтетических ящиках. Для разработки дают 99 публичных запросов. Итоговую оценку проводят на закрытом бенчмарке.
- **Качество.** `Recall@K` измеряет долю нужных писем в топе, `nDCG@K` — порядок релевантных результатов, `MRR@K` — позицию первого релевантного письма.
- **Скорость и модели.** Цель `p99 < 1 с` для обработки запроса, поиска и ранжирования. Сеть до браузера и отрисовка не учитываются. За превышение порога штрафуют. Использование API-моделей или моделей больше 3 млрд параметров на этапе отбора кандидатов или переранжирования тоже даёт штраф.
- **Сдача.** Репозиторий с кодом и README по запуску, веб-демо поиска и просмотра писем, проверяемая выдача (`query_id` → упорядоченный список `doc_id`) и защита.
- **Свобода реализации.** Архитектура и алгоритмы на выбор, переранжирование необязательно. Демо на localhost допускается. За публичную ссылку дают +1 балл. Дополнительные функции почты — отдельный бонусный трек.
