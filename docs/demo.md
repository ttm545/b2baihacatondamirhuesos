# Демо поиска по почте

Откройте почтовый архив с движком `dated:bm25`. После выбора ящика поле «Письма до даты» заполняется датой его последнего письма. Для повтора запроса организаторов замените эту дату значением из таблицы, вставьте запрос и нажмите «Найти».

## Что пришло вчера

В первом ящике таблицы установите дату 14.09.2028. Очистите запрос и нажмите «Вчера». Над результатами видны общее количество писем за 13 сентября и количество показанных писем за этот день. Раскройте «Типы писем за период», выберите тип со счётчиком и откройте одно из писем. Повторный клик по выбранному типу возвращает исходную выдачу. В каждом списке интерфейс показывает до 30 писем.

Подпись «Последнее письмо в ящике» указывает дату в архиве и сохраняется при ручном выборе точки отсчёта.
